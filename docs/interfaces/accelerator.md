# 加速器接口草案

状态：规划，尚未分配正式地址或实现寄存器。

首个候选任务为整数数组过滤与归约。实现前确定元素位宽、比较符号、
计数/累加位宽、溢出行为、对齐和空输入语义。

控制路径建议从 MMIO 起步，描述输入/输出物理地址、元素数量、阈值、启动、
忙/完成和错误状态。数据路径使用批量传输和本地缓冲，避免由 CPU 逐元素喂数。
初期可轮询完成，后续根据任务粒度增加中断或任务队列。

正式接口文档必须给出寄存器偏移、位定义、访问权限、复位值、任务完成条件、
错误恢复和复位行为。驱动调用序列需说明共享数据协议与内存顺序。
控制接口属于 `hardware/soc/` 与 `software/drivers/` 之间的稳定约定。
