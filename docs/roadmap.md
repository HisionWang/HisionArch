# 路线图

当前先完成 [CPU SoC 的 FPGA 接入](howto/fpga-soc.md)：选择板卡、补齐 MIG/XDC/
时钟配置，完成 DDR 校准、JTAG 下载、UART 和 LED 的上板验证。随后继续加速器主线。

研究主线为“CPU 参考程序 → 加速器独立实现 → 系统卸载 → 访存研究”。
CPU 使用固定依赖，为实验提供可追溯的控制与参考执行环境。

| 阶段 | 工作 | 验收标准 |
| --- | --- | --- |
| 1 | 明确过滤/归约任务语义、数据格式和 CPU 参考 | 多种输入规模具有独立可核对的结果 |
| 2 | 加速器与本地缓冲 | 任务级结果匹配参考，吞吐/资源和限制有记录 |
| 3 | MMIO、数据搬运、驱动、共享缓冲协议 | CPU 能发起任务并读取正确结果 |
| 4 | 端到端卸载与带宽竞争实验 | 报告完整开销、收益临界点和控制变量 |
| 5 | FPGA 板卡与真实 DDR | 上板完成同一工作负载，记录实际频率与数据路径 |
| 6 | 独立启动与实体成品 | 固件、板卡、外壳形成可重复部署的版本 |

各阶段按依赖推进。CPU 微架构升级、操作系统和高速外设在研究需要明确后安排。
每个实验先定义问题、计时边界和对照，再增加相关实现与观测信号。
