# 实验方法草案

## 对照与变量

比较同一输入上的 CPU 参考实现与加速器完整卸载路径。先固定 CPU gitlink、
频率、缓存、编译参数、内存模型与加速器配置，再逐项改变数组规模、
本地缓冲容量、批量大小、并发请求数和背景访存负载。

## 计时与指标

端到端计时包含必要的数据准备/缓存维护、启动、搬运、计算、完成同步与结果
读取。同时可分段记录，解释开销来源。分别报告冷/热缓存以及数据驻留假设。

记录任务延迟、吞吐、外部内存读写字节、等待周期、时钟频率和 FPGA 资源。
能耗结论需有明确测量范围与测量方法。每组结果先通过 CPU 参考校验。

## 解释边界

CPU 基线当前外部总线全局单 outstanding。若加速器支持更多并发，实验应明确
这项差异，并设置控制并发度的对照，避免把全部收益归于计算位置。
共享单通道 DDR 的结果只能支撑该数据路径下的结论。

## 复现材料

实现后增加实际配置、运行脚本、分析脚本与报告，记录源码提交、CPU 版本、
工具版本、随机种子、程序/bitstream 指纹、输入规模和成功校验值。
